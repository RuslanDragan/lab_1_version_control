# Лабораторна робота: Розв'язання практичних завдань на C# (.NET)

Навчальний проєкт, що містить консольні застосунки для демонстрації базових алгоритмів та структур даних мовою C#. Рішення складається з чотирьох підпроєктів (`task1`, `task2`, `task3`, `task4`).

## Структура репозиторію
- `task1/` — вихідний код та конфігурація першого завдання (`Task1.cs`, `Task1.csproj`)
- `task2/` — вихідний код та конфігурація другого завдання (`Task2.cs`, `Task2.csproj`)
- `task3/` — вихідний код та конфігурація третього завдання (`Task3.cs`, `Task3.csproj`)
- `task4/` — вихідний код та конфігурація четвертого завдання (`Task4.cs`, `Task4.csproj`)

## Системні вимоги
- **.NET SDK 10.0** (або актуальна версія .NET SDK)
- Встановлений Git
